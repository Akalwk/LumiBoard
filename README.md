
# LumiBoard

✨ A beautiful visual bookmark manager for Chrome.

LumiBoard turns your new-tab page into a clean visual dashboard where you can organize bookmarks, folders and boards.

## Features

- 🔖 Organize bookmarks
- 📁 Create folders
- 🗂️ Multiple boards
- 🖼️ Custom wallpapers
- 🔍 Search bookmarks
- 💾 Chrome bookmark storage
- 📱 Responsive design
- 🆓 Free and open source

## Installation

1. Download `LumiBoard-Like-Reference-v6.zip`
2. Extract the ZIP.
3. Open Chrome.
4. Go to `chrome://extensions`
5. Enable **Developer mode**.
6. Click **Load unpacked**.
7. Select the extracted LumiBoard folder.
8. Open a new tab.

Enjoy LumiBoard! 🚀
